# Thai Tax Calculator

เว็บแอปหน้าเดียวสำหรับประมาณการภาษีเงินได้แบบขั้นบันได โดยใช้ HTML, CSS และ JavaScript ล้วน

## วิธีเปิดใช้งานในเครื่อง
1. แตกไฟล์ ZIP
2. เปิดโฟลเดอร์ด้วย Visual Studio Code
3. เปิด `index.html` ในเบราว์เซอร์ หรือใช้ส่วนขยาย Live Server

## Deploy ด้วย GitHub Pages
1. สร้าง GitHub repository ใหม่
2. อัปโหลด `index.html`, โฟลเดอร์ `css` และ `js` (ไม่ต้องอัปโหลด ZIP อย่างเดียว)
3. ไปที่ Settings → Pages
4. เลือก Deploy from a branch → `main` → `/(root)` → Save
5. รอ GitHub สร้างเว็บไซต์ แล้วเปิด URL ที่แสดงในหน้า Pages

## หมายเหตุ
อัตราภาษีเป็นไปตามโจทย์ที่ให้มา และการคำนวณยังไม่ครอบคลุมกฎภาษี/รายการหักลดหย่อนทั้งหมดของกรมสรรพากร จึงเป็นเครื่องมือประมาณการ ไม่ใช่ระบบยื่นภาษีอย่างเป็นทางการ
